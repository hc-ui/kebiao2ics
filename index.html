课表转日历

把大学课程表变成手机日历文件（.ics）——iPhone、安卓、Apple Watch、电脑日历都能导入。
支持单双周、分段周数、自定义作息、上课提醒。纯网页本地运行，课表不会上传到任何服务器。

    下载后怎么导入手机日历？

    iPhone / iPad / Apple Watch
    1. 用 Safari 打开本页并下载 .ics 文件（微信内打开请先点右上角「在浏览器打开」）。
    2. 打开「文件」App → 「下载」文件夹，点击刚下载的 .ics 文件。
    3. 点「添加全部」，选择要放入的日历即可；Apple Watch 会自动同步。
    安卓（小米 / 华为 / 荣耀 / OPPO / vivo 等）
    1. 下载 .ics 文件后，用文件管理器点击打开，一般会弹出「导入到日历」。
    2. 如果系统日历不支持，安装「Google 日历」或使用系统日历设置里的「导入」功能。
    电脑：Outlook / Google 日历 / Apple 日历
    1. Outlook：文件 → 打开和导出 → 导入/导出 → 导入 iCalendar (.ics)。
    2. Google 日历：网页版右上角设置 → 导入和导出 → 选择文件导入。
    3. Mac 日历：直接双击 .ics 文件。
    常见问题
    • 学期中调课/节假日怎么办？直接在手机日历里删除或移动那几节课的日程即可；也可以回到本页改好周数重新生成导入（同一门课会自动覆盖，不会重复）。
    • 换手机 / 下学期还要用？点「备份课表配置」存一个 JSON 文件，下次「恢复课表配置」即可接着改。课表数据平时只存在你这台设备的浏览器里。
    • 导入错了想全部删掉？导入时选择放进一个新建的日历（如「2026秋课表」），想删时整个日历删掉即可。
